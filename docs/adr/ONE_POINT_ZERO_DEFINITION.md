## The bit-identity sunset (decided at the 0.28.0 gate, not before)
73038/13 anchored five releases by proving the engine's heart never
changed silently. It was never a claim that the curve is perfect —
near-flat ley-line at full attunement (−0.27%) is the open signal, and
only the owner's hands can say how it FEELS. If the feel pass says
retune: one-time deliberate rebalance — old baseline preserved in
history, new baseline pinned, all bands re-derived, trivialization
tripwires kept. If it says ship: the curve is the game. Either answer
is legitimate. The data and the owner's hands decide.
